# Character art for the Genshin themes

Each Genshin theme ships with original motif artwork (the SVGs one folder up).
To show actual character art instead, drop an image in this folder named after
the theme's character and rebuild — it's picked up automatically:

| Theme          | File name                                 |
| -------------- | ----------------------------------------- |
| Citlali        | `citlali.png` / `.webp` / `.jpg` / `.jpeg` / `.avif` |
| Skirk          | `skirk.png` / …                           |
| Hu Tao         | `hu-tao.png` / …                          |
| Raiden Shogun  | `raiden-shogun.png` / …                   |
| Furina         | `furina.png` / …                          |
| Ganyu          | `ganyu.png` / …                           |
| Mona           | `mona.png` / …                            |
| Lynette        | `lynette.png` / …                         |
| Layla          | `layla.png` / …                           |
| Xiangling      | `xiangling.png` / …                       |
| Yaoyao         | `yaoyao.png` / …                          |
| Amber          | `amber.png` / …                           |
| Xilonen        | `xilonen.png` / …                         |
| Escoffier      | `escoffier.png` / …                       |
| Lauma          | `lauma.png` / …                           |

Tall images with a transparent background (character renders / splash cut-outs)
look best: the art is anchored bottom-right of the content area and fades out
towards the left so text stays readable.

## Player bar accent

The small figure perched on the player bar can be swapped the same way: name
the file `<name>-bar.png` (e.g. `hu-tao-bar.png`). A small chibi or sticker
with a transparent background works best — it's shown up to 88px tall with
its bottom edge resting on the bar.
